# TSHP Stories

A GitHub Pages-ready static website containing an index and the complete Nagase Yasuo story.

## Important
The original Koyama website source was not provided, so this is a newly created visual design, **not an exact copy** of the Koyama site's styling. The Koyama card links to the existing live website. The original photograph's visible copyright credit is retained.

## Publish
1. Create a new GitHub repository (for example `tshp-stories`).
2. Upload **the contents** of this folder (index.html, nagase-yasuo.html, style.css, assets/).
3. In repository Settings → Pages, select Deploy from a branch, main, /(root), and Save.
4. Wait for GitHub Pages to publish; your link will typically be `https://YOUR-USERNAME.github.io/tshp-stories/`.

## Add a monthly story
1. Duplicate `nagase-yasuo.html` and rename it, e.g. `new-person.html`.
2. Update the title, biography, image and photo credit.
3. Upload the photo to `assets/`.
4. Add a new story card in `index.html` by duplicating an existing card and changing its links, image and title.
5. Commit changes. GitHub Pages will redeploy.

Before publication, confirm that the interviewee consented to publication and that the photographer permits publication/republication of the image. A copyright credit alone is not a license.
